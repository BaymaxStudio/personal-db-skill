# 个人资料库 —— 你自己的求职事实库

> 一句话：把你散落各处的求职材料，攒成一个**只属于你、越用越全**的个人档案；
> 填网申时不用再一份份翻文件、一遍遍复制粘贴。

这份说明写给**完全没接触过 AI 助手、也不会写代码**的你。照着做就行。

---

## 它帮你解决什么

投过网申的人都懂：同样的姓名、GPA、实习描述、获奖名称，
在几十个学校/公司的表单里要**反复填、反复复制**，还容易填错、填漏、中英对不上。

这个"个人资料库"把这些**事实**集中存一次，之后：

- 打开一个网页，所有信息分门别类摆好；
- 每条旁边有个"复制"，**点一下就复制**，直接粘到表单里；
- 中文表单看中文、英文表单切英文；
- 每条都能点开看**这句话出自你哪份材料**，绝不瞎编。

---

## 你需要准备什么

1. **一个能"看图"的 AI 助手**（也叫 agent / 智能体）。
   简单理解：就是一个你可以用大白话对话、并且能帮你读文件、读图片、在你电脑上干活的助手。
   它得**能看图片和 PDF**（因为你的成绩单、获奖证书常常是扫描件）。
2. **你的材料**：简历、成绩单、获奖证书、实习证明、项目结项材料、作品链接……
   有什么给什么，扫描件、截图、PDF、Word 都行。

> 你**不需要**懂代码、不需要懂命令行。真正敲命令、建文件这些活，都是助手替你做。
> 你只做两件事：**给材料** + **点头确认**。

---

## 三个让你放心的承诺

1. **有据可查**：每条信息都拴着一份原始材料和原文摘录，点开就能核对。
2. **你说了算**：任何信息进正式库之前，助手都会**先列给你看**，你说"对 / 改这里 / 这条删掉"，它才写进去。它不会自作主张。
3. **只在你自己的电脑上**：数据库、你的材料、导出文件全都存在本地，**不上传、不外发、不交给任何第三方**。

---

## 怎么用（日常就这几步）

### 第一次

跟你的助手说一句：

> “帮我用 personal-db 这个技能，给我建一个个人资料库。”

它会在你电脑上建好一个文件夹（默认叫 `个人资料库`），里面有个 **`materials`** 子文件夹——
**这就是你放原始材料的地方**。

### 每次想加东西

1. **把材料丢进 `materials` 文件夹**（拖进去就行）。
2. 跟助手说：**“把 materials 里新加的材料整理进我的库。”**
3. 助手会把它从材料里读到的信息，**一条条列给你**：字段是什么、准备录入什么值、出自哪份文件。
   你逐条回它：**“对” / “这个改成……” / “这条不要”**。
4. 确认完，它写进库、自动存一份备份。

### 查看和使用（填表时）

- 打开那个文件夹里的 **`web`** 子文件夹，**双击 `打开资料库.command`**；
  浏览器会自动打开你的资料库。
- 想复制哪条，**点它一下**就复制好了，直接粘到网申表单。
- 顶部能搜索、能切中/英；每条后面的 **“N证”** 点开是它的出处。

> 第一次双击 `.command` 若被 macOS 拦住，在文件上**右键 →「打开」**，确认一次即可。

## 越用越好用

不用一口气把所有材料都喂进去。**边投边攒**最自然：

- 这次网申问到一段你还没录的经历 → 顺手把相关材料丢进 `materials`，让助手加进去；
- 拿了新证书、结了新项目 → 随手补进去。

攒得越多，下次填表越省事。这就是它"越用越顺手"的原因。

## 名词小抄

| 你会看到 | 是什么 |
|---|---|
| `materials` 文件夹 | **你放原始材料的地方**（唯一入口，助手只从这里取证据）。 |
| 查看器 / 那个网页 | 只读的浏览页面，用来看和复制，改不了数据。 |
| 候选 / 确认 | 助手先给"候选"，你"确认"后才成为正式记录。 |
| 快照 / 导出 | 一份可交给别的工具用的正式副本（只含你确认过的内容）。 |
| 备份 | 每次写库前自动存的旧版本，存在 `backups` 里，出岔子能找回。 |

## 常见问题

**我完全不懂技术，能用吗？**
能。你只负责给材料和点头，其余交给助手。

**我的数据安全吗？**
所有东西都在你自己电脑上，不联网、不外传。你也可以随时把整个文件夹删掉。

**网页打不开 / 打开是空白？**
让助手帮你看一眼：常见原因是服务没起来，或 8733 端口被别的程序占了，它会处理。

**助手会不会把不确定的东西也塞进来？**
不会。凡是拿不准的，它会问你；凡是要进库的，都会先让你确认。

**材料能删吗？删了库里的信息会没吗？**
库是独立存的。但为了"有据可查"，建议材料别乱删；真要整理，先问问助手。

有任何一步卡住，直接把情况说给你的助手，它会帮你解决。
